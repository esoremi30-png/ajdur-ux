Detailed options — per service

Decision 1 — Self Discovery (currently live on home)
Decide Now
⚠ What does the home screen "Self Exploration" free reading actually give the user?
Option A — Full free reading
The home reading gives users a complete self-discovery result with no paywall. Consultation is a separate premium path for deeper personalised guidance.
Option B — Preview + Consultation upsell ✦ Recommended
The home reading gives a meaningful preview (e.g. core trait reveal), then invites users to book a Consultation for a full, personalised reading. Clear value ladder.
Option C — Free reading + optional paid upgrade
Full free reading always available. Users can pay for a live Consultation as an additional layer — not replacing the free reading.
Flow impact: Option A = no CTA to Consultation from home. Option B = home reading ends with a "Book Consultation" prompt. Option C = two parallel paths, both valid. This changes the tab bar and home screen CTA design.
Decision 2 — Life Coaching, Life Path & Spiritual Healing (Coming)
Coming
⚠ Where do these services live and how are they accessed?
Option A — Consultation-only
These are premium services only bookable via Consultation (Standard / Platinum tier). Not available as self-service free readings. Coupon = discount on booking.
Option B — Dual path ✦ Recommended
A lightweight free reading is available via Self Exploration for each. The full, interactive, guided session requires booking a Consultation. Coupon unlocks the paid path at a discount.
Option C — Advance Insights cards
These appear as new cards in the Advance Insights grid alongside Fortune Wheel, Oraculum etc. User taps → gets a reading. Paid depth gated by coupon.
Flow impact: Option B is recommended because it uses the existing app structure (Self Exploration → Consultation upsell), adds clear value for free users, and gives the Consultation flow a clear differentiation. Option A risks making free users feel the app has nothing for them.
Decision 3 — Fortune Wheel & Compass (Coming)
Coming
⚠ Are these free interactive tools or coupon-gated premium experiences?
Option A — Free tools ✦ Recommended
Both are free interactive experiences in the Advance Insights grid. They generate engagement and lead users toward Consultation for deeper interpretation. High viral potential as shareable results.
Option B — Coupon-gated
Require a coupon to access. Positions them as premium. Risk: creates friction for discovery and reduces user exploration if free users have no way to engage.
Option C — Free basic, paid depth
Fortune Wheel spins are free with a generic result. Full personalised interpretation requires a coupon or Consultation booking. Best of both.
Flow impact: Option A allows these to sit freely in the Advance Insights grid — no gate, no coupon check. Option B adds a "redeem coupon" screen before access. Option C requires a tiered result display screen.
Decision 4 — Oraculum & Physiognomy / Face Reading (Coming)
Coming
⚠ Same question as D3, plus: are Oraculum and Dream Interpretation the same feature?
Option A — All free
Oraculum and Physiognomy join the free Advance Insights grid. No coupon needed. Volume play — more users engage and discover deeper services.
Option B — Free preview, coupon for full ✦ Recommended
User submits a dream / facial image → gets a brief interpretation free. Full reading (3× depth, PDF report, practitioner notes) requires a coupon. Smart monetisation for premium AI-enhanced features.
Option C — Paid Consultation only
These require a Consultation booking to access. Oraculum = Special Request tier. Physiognomy = Platinum tier add-on.
Additionally clarify: Is "Dream Interpretation" in the current Advance Insights grid the same product as the coming "Oraculum"? If yes, rename consistently. If different, define the distinction before building the screen.
Decision 5 — What Coupon Types Exist?
Decide Now
⚠ The "Coupon Type" dropdown in the form needs real options — what are they?
Proposed type list
• Consultation discount

• Store voucher

Team to confirm, add or remove.
How coupons are issued
Is this a manual process (team reviews and emails a code), or automated (auto-generated on submission)? This affects back-end and the confirmation UX.
Coupon vs subscription
Are coupons one-time use or ongoing (e.g. monthly access)? If recurring, consider replacing the coupon model with a membership/subscription screen instead.
Flow impact: Until coupon types are defined, the form dropdown cannot be built. This also affects whether the Advance Insights gated services show a "redeem coupon" CTA or a "subscribe" CTA.

Deliverable 04

UX Audit — Updated from v1

New issues added based on the service architecture review. Issues from v1 that still apply are retained. New items relate to service clarity and the decision gaps identified above.

Strengths

✦
Genuinely unique service range
No mainstream app offers Face Reading + Dream Interpretation + Life Path + Spiritual Academy in a single product. This is the app's biggest competitive advantage.
✦
Strong copy on onboarding slides
"Know Yourself", "Blueprint on Your Face", "Compass Within" — these are emotionally resonant, benefit-led headlines that work.
✦
Consultation tier structure is clear
Standard → Platinum → Special is an intuitive value ladder users can self-select into without explanation.
✦
Logical navigation categories
Five menu items map cleanly onto five user intents. No overlap or confusion at the category level.

Issues

01
Inconsistent visual theme — two different apps in one
Grey-header utility screens (Coupon, menu) sit alongside rich dark spiritual screens (Education, Onboarding). Users experience a split product. A unified light-futuristic system fixes this without sacrificing the premium spiritual feel.
High
02
No clear signal of what is free vs what is paid
Users cannot tell from the Advance Insights grid which cards require a coupon and which are free. This creates friction and potential disappointment when a gated screen appears unexpectedly.
High
03
Coupon system is undefined — form has no context
The "Request Coupon" screen has a generic "coupon type" dropdown with no real options. Users don't know what a coupon unlocks, how long it takes to receive, or whether it's for services or the store.
High
04
Grey Submit button on coupon form doesn't communicate action
The grey CTA looks disabled. Primary CTAs must always be the teal/indigo filled pill — the current Submit reads as inactive, causing users to hesitate.
High
05
Side menu uses plain white background — brand disconnect
The current drawer uses a white/light background with plain black text — looks like a default component, not a spiritual premium product. Needs brand-consistent treatment.
Medium
06
Advance Insights grid cards are visually identical
All 8 cards use the same grey tile with a centred icon and label. Zero differentiation between a free card and a coming/gated card. Add status indicators and subtle accent colours per category.
Medium
07
Education section is a dead end for non-enrolled users
Users who tap Education and are not enrolled see a Login button that redirects externally — no onward journey is offered. Add a "Learn about enrolment" path or community preview.
Medium
08
Dream Interpretation vs Oraculum overlap
Both appear to be interpretation services. If they are the same product with different names, consolidate. If different, the distinction must be explained clearly on each card.
Medium
09
Typography is uneven across screens
Body text, labels and descriptions use inconsistent sizes — the Consultation screen is well-set, the Request Coupon form uses light placeholder text as the primary label. A 4-step type scale fixes this globally.
Medium
10
"Horifing Number" label typo in Advance Insights grid
Visible spelling error reduces product credibility. Correct to "Horrifying Number" (or confirm the intended name) before public launch.
Polish

Opportunities

Free vs paid clarity as a trust builder
Clearly labelling free items with a "Free" badge and gated items with a lock icon transforms a potential source of friction into a transparency signal that builds user trust. Users who know what's free will explore more freely and convert more easily to paid services.
Consultation as the premium hub — not just one menu item
Every free reading result screen should surface a contextual "Go deeper with a Consultation" CTA. This turns the entire Self Exploration experience into a funnel for the highest-value service rather than a standalone feature.
Store as a retention tool, not an afterthought
When launched, the store (Books, Incenses, Healing Products) should be surfaced contextually — e.g. after a Spiritual Healing reading, recommend the healing products. This increases average order value and session depth.

Priority Implementation

In order of impact. Items 1–3 are decisions, not development — they unblock everything else.

01
Team: Resolve Decision Matrix items 1–5 above
Until the free/paid/coupon model is defined for each ambiguous service, user flows, backend gating, and screen CTAs cannot be finalised. This is the highest-priority item — no design or dev work unblocks before this.
02
Define the full list of coupon types and the redemption mechanism
Is coupon fulfilment manual (team emails a code) or automated? What are the types? This directly unblocks the Request Coupon form dropdown and the gated service access screens.
03
Clarify Oraculum vs Dream Interpretation — same or different?
If the same: rename consistently across the app and remove the duplicate card. If different: write a one-line distinction to display on each card.
04
Apply Futuristic Light theme globally — start with headers
Replace all grey headers with the white/light-indigo surface system. This single visual change removes the biggest inconsistency and can be done in 1–2 days before any other redesign work.
05
Add free/paid/coming badges to Advance Insights cards
Users need to know at a glance what is available to them. Add status indicators to each card in the grid — green "Free", indigo "Paid", gold "Coming" badges. This requires no backend change, only UI.
06
Replace Submit button on coupon form with primary indigo CTA
The current grey button looks disabled. Takes 15 minutes to fix and immediately increases form completion rate.
07
Fix "Horifing Number" typo in Advance Insights grid
Single string change. Correct to the intended label before any public-facing release or marketing.
