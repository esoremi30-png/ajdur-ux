8 Confirmed User Flows

Every major journey the app must support. Each flow connects to a revenue outcome — consultation bookings, ad revenue, or long-term retention.

Flow 1 — First-Time User Onboarding
Install → 3 Onboarding slides (Skip available) → Reveal My Blueprint → Home → Free reading → Consultation upsell
Flow 2 — Daily Returning User
Re-open → Daily oracle (ad revenue hook) → Explore or Watch Ad → Result → Consultation upsell
Flow 3 — Consultation Booking (Speak to Prof. Kewunla)
Menu → Consultation page → Choose tier (₦10K or ₦35K) → Optional coupon → Confirm → Booked
Flow 4 — Discover Hidden Patterns (Advance Insights)
Grid → Tap card → Free (direct) or Gated (Pay/Watch Ad popup) → Result → "Speak to Prof. Kewunla" upsell
Flow 5 — Rewarded Ad (Watch & Unlock)
User taps "Watch & Unlock" → Full ad plays → Starter reading unlocked → Result → Consultation upsell. Live at launch.
Flow 6 — Daily Wisdom Center
Menu → Daily Wisdom → Oracle (free/ad unlock) → Teaching → Academy class login (separate) → Trust built → Consultation CTA

Content by Prof. Kewunla (weekly batch) + Team scheduling. Daily rotation auto-scheduled. Premium oracle unlocked via "Watch & Unlock" ad.

Flow 7 — Unlock Discount Access
Menu → Page → Path A: Fill form → Request sent → Code emailed. Path B: Watch & Unlock. Both paths resolve to access.

5 coupon types in dropdown. WhatsApp Contact Us button links to +234 XXX XXX XXXX. Full Free Consultation = manual approval only.

Flow 8 — Post-Insight Upsell
Every insight result screen → "Need Deeper Answers?" block → "Speak to Prof. Kewunla" → Consultation booking. This is mandatory on all result screens.

Per the brief: "This is the strongest conversion path. Must exist." Dual revenue: ad revenue already earned + consultation booking.
